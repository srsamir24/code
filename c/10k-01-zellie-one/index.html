The $10,000 website. All 5 prompts.

These are the prompts behind Zellie One: a 3D product site that turns as you scroll, re-skins itself with one colour, and ends on a magnetic button. Run them in order, each one builds on the file from the last.

Open the live site View the full code

You need a 3D model as model.glb. We made ours with a text-to-3D generator, then shrank it with gltf-transform.

013D hero

Build a dark single-page product site in one HTML file with three.js 0.170 from a CDN. Load model.glb (over-ear headphones), centre and scale it to fit any screen. Put a giant outlined headline "ZELLIE ONE" behind the canvas, letters rising one by one on load. The model drops in, floats, and tilts toward the cursor. One font only: Inter Tight.

02Scroll turntable with callouts

Add a 420vh section with a sticky 100vh stage. As you scroll through it, the model turns a full 360° with eased keyframes. Pin 4 callouts to points on the model: project each 3D point to the screen every frame and draw a dashed line from it to its label.

03Live colour swap

Add a finishes section with 4 swatches in teal, purple, magenta and indigo. Scrolling walks through them, clicking jumps to one. One colour must drive everything: the model's material via a shader uniform, the rim light, the background glow and the accent text. Blend smoothly, never snap.

04Feature cards with live visuals

Add a features section: a bento grid of 5 cards, each with its own live visual (a noise wave that flattens when a toggle switches on, a battery ring that fills, sound dots orbiting a head, EQ bars, a charge bar). Cards reveal as they enter. Under the cursor each card gets a spotlight that follows along its border and tilts a few degrees. One font only.

05Magnetic button

End with the model landing in the centre, a big headline and a round "Pre-order" button that pulls toward the cursor when it gets within 260px, with the label moving a bit further than the button. Add a slow marquee footer.

Honest take: this is a beautiful site, and for most businesses it's overkill. Your bakery doesn't need a 3D turntable. Use the parts, not the whole thing.
