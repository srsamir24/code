Depth field hero. The prompts.

These are the prompts behind the depth field: 9,000 points that part around your cursor and spring back, used as a calm hero background on desktop and phone. Run them in order, each one builds on the file from the last.

Open the live page View the full code

One HTML file, three.js 0.170 from a CDN. No build step, no model to download.

01The field

Make a full-screen three.js 0.170 canvas in one HTML file. Scatter 9,000 points in a deep box in front of the camera, small and dim far away, larger and softer up close. Mostly deep purple with a few teal ones. Draw them with a custom additive shader so close points glow. The camera drifts slowly in a loop so the field never sits still.

02Cursor wake

Turn the cursor into a ray through the field. Points inside a cone around that ray get pushed out and dragged along with the cursor's speed, then spring back with damping. Points that are pushed light up teal. Run the simulation in small fixed steps so it looks the same at any frame rate.

03Hero on top

Put a simple hero over the canvas: a wordmark and four text links, a big bold headline at the bottom left with one word in teal, one line under it, and a thin footer row. Add a soft dark radial pool behind the headline so the dots never fight the text. One font only: Inter Tight. On phones, swap the links for "Menu" and scale the headline to the width.

Honest take: this is a great hero, and for most businesses it's overkill. Your plumber doesn't need a particle field. Use it where the wow is the point.
