Zellie Tide. The prompts.

The prompts behind a dive watch site: colour columns the watch crosses, a bezel that only turns one way, and a lights-out section where only the markers stay lit. Run them in order, each one builds on the file from the last.

Open the live site View the full code

You need a 3D watch as model.glb. We made ours with a text-to-3D generator, then shrank it with gltf-transform.

013D hero

Build a dark single-page product site in one HTML file with three.js 0.170 from a CDN. Load model.glb (a dive watch), centre and scale it to fit any screen. Big product name under the watch, a small row of specs below it. The watch tilts toward the cursor. One font only: Inter Tight.

02Colour columns

Add a section where the screen is four full-height vertical columns, one per dial colour, all four depths of the same dark sea. Scrolling carries the watch across them. A shader splits the dial at the column edge so the new colour wipes across it. Clicking a column jumps there, and arrow keys work. In portrait the current column opens up and the others become strips with vertical names.

03One-way bezel

Add a macro view of the watch bezel with 120 clicks. You can drag it, but it only turns one way, and dragging the wrong way shows "One way only". Scrolling ratchets it forward and scrolling back never undoes it. Show the click count, and add a button that walks the triangle onto the minute hand.

04Lights out

Add a section where the room goes black and only the markers stay lit: one lume colour on the indices, another on the minute hand. Each marker holds its own charge. Scrolling moves through hours in the dark and the brightness slides down a decay curve. The cursor is a torch that recharges the markers it passes. A light switch, also on the L key, resets the night.

Honest take: this is a beautiful site, and for most businesses it's overkill. Your plumber doesn't need a one-way bezel. Use the parts, not the whole thing.
