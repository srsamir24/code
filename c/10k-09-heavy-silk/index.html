Heavy silk hero. The prompts.

Prompts for a heavy silk hero background: dark satin you can drag, which takes a couple of seconds to settle back, on desktop and phone. Run them in order, each one builds on the file from the last. The full code of the finished page is linked below if you want to compare.

Open the live page View the full code

One HTML file, raw WebGL2. No libraries, no build step, no video, no 3D model.

01The cloth

Build one HTML file with raw WebGL2, no libraries, Inter Tight only. Full-screen fragment shader: heavy oxblood satin, one hue plus light. A few broad diagonal folds with soft crease tops and round valleys, fanning out as they fall. Analytic normals, so one pass. A wide anisotropic satin sheen along the threads, real shadows cast by the crests, dither to stop banding.

02It has weight

Add a coarse grid in JS, about 15,000 cells, with sideways drag u,v and press depth w. Tension spreads a pull, a weak spring and heavy damping bring it home in about two seconds. Draw the pleats at position minus drag, so the cursor carries the folds, and let the grip lag behind the cursor a little so the cloth feels heavy. Where the fabric gets compressed, raise the folds, and clamp how tightly they can pinch so they never comb into strands.

03The hero

Add a simple hero: wordmark, three text links with "Menu" on phones, one heavy headline, one line of text, a thin footer. Keep the corner behind the copy in shadow so the text stays readable. Touch drags the cloth and lets go on lift. Lower the resolution if the frame rate drops. prefers-reduced-motion draws one still frame.

Honest take: this is a great hero, and for most businesses it's overkill. Your plumber doesn't need a silk curtain. Use it where the wow is the point.
